# Архитектура v3: Local CA / Offline Motion Gamepad (Go Edition)

> **Статус:** Окончательная рабочая архитектура для реализации  
> **Дата:** Сентябрь 2026  
> **Стек:** Go (Golang) — единый статический бинарник `.exe` без рантайм-зависимостей  
> **Цель:** Сенсорный гироскопический геймпад через мобильный браузер (iOS / Android), 100% автономный, без внешних серверов, с транспортной задержкой 1–3 мс и гарантией работы на 5–10 лет без поддержки автора.

---

## 1. Концепция и фундаментальный принцип

ПК-приложение представляет собой единый автономный процесс на Go. Внутри упакованы:
1. **Собственный Certificate Authority (CA)** на базе `crypto/x509` (генерация корневого и leaf-сертификатов).
2. **mDNS Responder** для анонсирования домена `gamepad.local`.
3. **HTTPS + WSS сервер** для отдачи встроенного UI и приёма потока телеметрии.
4. **Calibration & Recenter Engine** для компенсации неизбежного дрейфа мобильного гироскопа.
5. **Cemuhook DSU сервер (UDP 26760)** для нативной интеграции с эмуляторами (Cemu, Yuzu/Ryujinx-форки, Dolphin и др.) без привязки к конкретным процессам.

## 2. Адресация и обход специфики ОС (iOS vs Android)

Главная сложность — разное поведение мобильных браузеров в локальной сети:

### 2.1. Apple iOS (Safari)
* **Проблема:** Safari намертво блокирует сокеты `wss://` на самоподписанных сертификатах и требует валидный Secure Context.
* **Решение:** 
  1. Выпуск Root CA сертификата на 10 лет.
  2. Генерация профиля `.mobileconfig` (MIME-тип: `application/x-apple-as-config`).
  3. Однократная установка профиля в iOS (Настройки $\to$ Основные $\to$ VPN и управление устройством $\to$ Доверие сертификатам).
  4. Адресация через mDNS (`https://gamepad.local:PORT`), благодаря чему смена IP роутером не ломает сертификат.

### 2.2. Google Android (Chrome)
* **Проблема:** Chrome на Android исторически плохо резолвит имена `.local` (mDNS) через локальный Wi-Fi, отправляя запросы во внешние DNS.
* **Решение:** 
  1. Для Android **основным каналом является прямой LAN IP** (`https://192.168.x.x:PORT`).
  2. Leaf-сертификат содержит в SAN (Subject Alternative Names) как `gamepad.local`, так и текущий локальный IP.
  3. На Android не требуется устанавливать профили: пользователь просто жмёт «Дополнительно» $\to$ «Перейти на сайт», и Chrome в отличие от Safari **не блокирует** WebSocket.

## 3. Компоненты системы

### 3.1. CA / Cert Manager (`crypto/x509`)
* Генерирует корневой сертификат Root CA (ECDSA P-384 или RSA 4096) со сроком жизни 10 лет.
* Приватный ключ хранится локально в `%APPDATA%/gamepad/ca/` с правами доступа текущего пользователя.
* Выпускает leaf-сертификат для `gamepad.local` + локального IP (срок 825 дней с автоматическим обновлением).

### 3.2. Pairing & QR Generator
* **QR №1 (iOS, один раз при первом запуске):**  
  Ссылка `http://192.168.x.x:PORT/ca.mobileconfig` для быстрой установки корневого профиля.
* **QR №2 (Основной, для игры):**  
  Ссылка вида `https://gamepad.local:PORT/?token=<one-time-token>` (для iOS) и `https://192.168.x.x:PORT/?token=<one-time-token>` (для Android).
* **Безопасность:** Одноразовый токен в URL защищает сервер от несанкционированного подключения соседей по Wi-Fi.

### 3.3. HTTPS + WSS Server
* Статика веб-клиента (HTML5, JS, CSS, иконки) компилируется прямо в Go-бинарник через директиву `//go:embed` — никаких внешних файлов.
* WSS-эндпоинт принимает пакеты телеметрии `{alpha, beta, gamma, ax, ay, az, buttons, ts}`.

### 3.4. Calibration & Recenter Engine
* **Recenter Button:** На экране телефона размещена кнопка сброса нуля. При нажатии текущая ориентация телефона принимается за нейтральную (прицел по центру экрана).
* **Сглаживание и фильтрация:** Легковесный экспоненциальный фильтр (EMA) для устранения дрожания сенсора без добавления задержки.

### 3.5. Cemuhook DSU Server
* Реализует официальную спецификацию DSU протокола по UDP на порту 26760.
* Поддерживает широковещательные ответы на DSU-запросы эмуляторов (Cemu, Yuzu, Ryujinx, Dolphin).
* Чистая реализация протокола: независима от судьбы конкретного эмулятора.

## 4. Пользовательский флоу

### Android:
1. Запустил `gamepad.exe`.
2. Сканировал QR-код камерой.
3. В Chrome нажал «Дополнительно» $\to$ «Перейти на сайт».
4. Готово, играем.

### iOS (Первый запуск — разовая настройка на 60 сек):
1. Запустил `gamepad.exe` $\to$ отображается экран первого запуска с QR №1.
2. Скан QR №1 $\to$ Safari показывает «Профиль загружен».
3. Настройки $\to$ Профиль загружен $\to$ Установить.
4. Настройки $\to$ Основные $\to$ Об этом устройстве $\to$ Доверие сертификатам $\to$ Включить тумблер для Gamepad CA.
5. Нажал в ПК-программе «Далее» $\to$ появился QR №2.
6. Скан QR №2 $\to$ Safari открывает геймпад с чистым зеленым замочком без единого предупреждения.

### iOS (Все последующие запуски):
1. Запустил `gamepad.exe` $\to$ сразу сканировал QR №2 $\to$ играем.

## 5. Латентси-бюджет (Честная раскладка)

| Этап передачи | Время | Кто контролирует |
| :--- | :--- | :--- |
| **Опрос сенсора в мобильном браузере** | **~16.6 мс** (потолок 60 Гц) | Ограничение браузера/ОС |
| **Сериализация JSON/Binary на телефоне** | **< 0.5 мс** | Наш JS-клиент |
| **Транспорт по Wi-Fi LAN (WSS)** | **1 – 3 мс** | Наш локальный сервер |
| **Обработка на ПК + DSU ретрансляция** | **< 0.5 мс** | Наш Go-сервер |
| **Опрос DSU эмулятором** | Синхронно с FPS игры | Эмулятор (Cemu/Yuzu) |
| **ИТОГОВАЯ ЗАДЕРЖКА (End-to-End)** | **~18 – 20 мс** | **Отличный отзыв для шутеров/Зельды** |

> **Сетевая задержка нашего решения — всего 1–3 мс**. 90% времени уходит на физический опрос датчика операционной системой смартфона.

## 6. Внешние факторы и защита от сбоев

1. **Windows Firewall:**
   * При первом запуске приложение выведет понятную подсказку в терминал/GUI о необходимости разрешить доступ в Брандмауэре Windows для локальной сети.
2. **AP / Client Isolation на роутере:**
   * Если роутер изолирует Wi-Fi клиентов друг от друга, приложение выведет предупреждение при отсутствии коннекта через 10 секунд.
3. **Энергосбережение экрана iOS/Android:**
   * Веб-клиент использует `navigator.wakeLock` (и fallback на скрытое зацикленное видео `NoSleep.js`), чтобы экран не блокировался во время игры.

## 8. Долговечность «Zero Maintenance» на 5–10 лет

1. **Единый бинарник:** Go компилируется в самодостаточный `.exe`. Никаких runtime Node.js, Python, Electron или внешних DLL.
2. **0 внешних API:** Никаких серверов авторизации, баз данных, облачных релеев или сертификационных центров.
3. **Открытый протокол:** Cemuhook DSU — стабильный стандарт эмуляции с 2017 года.
